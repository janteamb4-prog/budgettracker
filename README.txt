BUDGETFLOW — BUDGET TRACKER

FILES
- index.html: page structure
- style.css: glassmorphic visual design and responsive layout
- script.js: calculations, expense management, local saving and tools

HOW TO RUN
1. Extract the ZIP archive.
2. Keep index.html, style.css and script.js together in the same folder.
3. Open index.html in Chrome, Edge, Firefox or Safari.

FEATURES
- Set a cutoff budget and name the cutoff period.
- Add expenses with a name, category, amount and date.
- Rename/edit or delete an expense.
- Automatic total expenses, remaining balance and budget-use progress.
- Search expenses and filter by category.
- Export expense records to CSV.
- Print the report or save it as PDF.
- Light and dark glassmorphic themes.
- Automatically saves data in browser local storage.

PRIVACY / STORAGE
The tracker runs locally in your browser. Your entries are stored in that browser on that device.
Clearing browser site data may remove saved tracker data. Export CSV periodically as a backup.
